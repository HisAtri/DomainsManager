# DomainsManager Web

基于 React、TypeScript、Tailwind CSS v4 和 Radix UI 的前端应用。它通过 Vite 代理调用后端的 `/api/v1` 接口，不使用演示数据。

## 启动

先启动后端（默认 `127.0.0.1:7920`），再执行：

```powershell
cd frontend
npm install
npm run dev
```

开发服务器运行在 `http://127.0.0.1:5173`；`vite.config.ts` 将 `/api` 请求代理至后端。

## 已对接的接口

- 本地登录、注册、Token 刷新、退出登录
- 当前用户资料、密码、监控偏好
- 域名列表、创建、详情、更新、软删除
- 域名刷新任务、任务轮询、检查历史
- 管理员用户查询、封禁、解封
- 管理员全局域名查询

## 后端变更对接记录

- 2026-08-24：检查历史接口的 `changed_fields` 现在会在成功刷新后的快照发生变化时返回字段名；现有 `Check` 类型无需调整。界面可将非空数组显示为本次域名信息变更。
- `next_check_at` 已由后端维护，暂不出现在普通用户域名响应中；后续 Scheduler 功能开放时会在本文件和 OpenAPI 契约中记录前端改动。

刷新任务中心仅展示当前浏览器会话创建的任务，因为后端目前没有任务列表接口。
